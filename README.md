# FyCode

FyCode é um ambiente desktop para transformar pedidos em projetos reais usando agentes de IA pela linha de comando, sem exigir que o usuário trabalhe diretamente no terminal.

## Download

**Versão atual:** FyCode Beta V1.1 — `0.1.1`

- **Windows 10/11 64 bits:** o instalador está disponível na página de Releases deste repositório.
- **macOS:** em validação. Ainda não disponível para download público.

## Requisitos

- Windows 10 ou 11 64 bits
- Antigravity CLI configurada e conectada
- Conta FyCode
- Conexão com a internet

## Verificação do download

Os downloads oficiais acompanham o checksum SHA-256 de cada instalador (arquivo `SHA256SUMS.txt` na Release). Antes de instalar, você pode conferir se o arquivo baixado é exatamente o publicado.

SHA-256 do `FyCode-Setup-0.1.1.exe`:

```
fbf16827231d03ee42652c90189882d266a0c022b574502163d99e2351b81764
```

No PowerShell:

```powershell
Get-FileHash .\FyCode-Setup-0.1.1.exe -Algorithm SHA256
```
